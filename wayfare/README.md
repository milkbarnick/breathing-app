# Wayfare

A native iPhone travel itinerary app, with a Cloudflare Worker backend, built by a simulated app studio.

- **Start here:** [`company/REVIEW.md`](company/REVIEW.md), which covers the current iteration, how to run it, and the questions for you.
- `company/`: the studio's operating model, decision log, product brief, UX spec, design system, engineering notes, QA report, and release checklist.
- `docs/api-contract.md`: the API contract that both the app and the backend implement.
- `ios/`: the SwiftUI app (XcodeGen project). Setup is in `ios/README.md`.
- `backend/`: the Cloudflare Worker, D1 database, APNs push, and AI import. Setup is in `backend/README.md`.
