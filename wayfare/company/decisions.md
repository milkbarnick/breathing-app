# Decision Log

Decisions the studio made on the owner's behalf. Each one is open to review.
Anything marked **[OWNER]** is waiting on your call.

| # | Decision | Why | Status |
|---|---|---|---|
| D1 | Working name **Wayfare**, bundle id `com.wayfare.app` | Placeholder. Check App Store name availability before launch. | **[OWNER]** |
| D2 | iOS 17+, SwiftUI, SwiftData, MapKit, no third-party iOS dependencies | Modern APIs (SwiftData, Observation). ~95% of active iPhones run 17+. Zero-dependency builds are easy to maintain. | Proposed |
| D3 | Xcode project generated by **XcodeGen** (`ios/project.yml`) | A readable, diffable project file that agents can edit safely. One `xcodegen` command produces the `.xcodeproj`. | Proposed |
| D4 | Backend is a **Cloudflare Worker + D1 (SQLite) + Cron Triggers** | Same platform as your existing Strava worker. Free tier covers personal use. D1 gives relational queries for sharing. | Proposed |
| D5 | **Sign in with Apple** is the only login | No passwords to store. Fastest App Store approval path. Required anyway if we ever add other social logins. | Proposed |
| D6 | Offline-first: SwiftData is the local truth, synced by delta cursor, last-write-wins | Travel means airplane mode and bad roaming. The app must work fully offline. | Proposed |
| D7 | Item reminders are **local** notifications. Collaborator alerts and the daily briefing are **server push** (APNs) | Local reminders fire even with no signal. Server push is only for things the device can't know. | Proposed |
| D8 | AI import (paste a confirmation email → draft items) runs server-side through the Anthropic API | The API key never ships in the app. The user reviews every draft before anything is saved. | Proposed |
| D9 | MVP excludes: packing lists, expenses, document vault, widgets / Live Activities, flight-status tracking | Keeps v1 shippable. All are on the roadmap in the product brief. | **[OWNER]** |
